# MusicDEV

Développement de l'oreille musicale : dictées mélodiques et rythmiques, intervalles, progressions d'accords,
lecture de notes, lecture à vue, lecture rythmique, solfège, lecture appliquée et bibliothèque théorique.

Application web installable (iPhone, Android, Chromebook, ordinateur) qui fonctionne hors ligne une fois installée.

- `index.html` : l'application complète
- `sw.js` : mise en cache pour l'utilisation hors ligne
- `manifest.webmanifest`, `icons/` : installation sur l'écran d'accueil
- `abcjs-basic-min.js` : notation musicale ([abcjs](https://github.com/paulrosen/abcjs), licence MIT)
- `fonts/` : polices sous licence SIL Open Font License
