# MusicDEV — translation glossary (French source → English / Spanish)

Audience: secondary-school music students (Quebec). French uses informal "tu". Use informal "you" (EN) and "tú" (ES).

## Note names
- FR do ré mi fa sol la si → EN C D E F G A B → ES do re mi fa sol la si (lowercase, no accent on "re").
- Accidentals keep the symbols ♯ ♭ ♮ 𝄪 𝄫. FR "fa♯" → EN "F♯" → ES "fa♯". FR "si♭" → EN "B♭" → ES "si♭".
- Words: dièse → EN sharp / ES sostenido ; bémol → flat / bemol ; bécarre → natural / becuadro ; double dièse → double sharp / doble sostenido ; altération(s) → accidental(s) / alteración(es) ; armure → key signature / armadura.
- "do central" → middle C / do central.
- Keys: "Ré majeur" → "D major" / "Re mayor" ; "fa♯ mineur" → "F♯ minor" / "fa♯ menor". Tonalité → key / tonalidad.
